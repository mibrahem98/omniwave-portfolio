# OmniWave

**OmniWave** مركز وسائط محلي للهواتف مبني بـ Expo وReact Native. يدير الموسيقى والفيديوهات المحلية وتفضيلات العرض والاستماع على الجهاز أولًا، مع واجهة عربية داعمة لاتجاه RTL، ودون حاجة إلى حساب أو مزامنة سحابية لتشغيل الوظائف الأساسية.

> **فكرة المشروع:** استيراد الموسيقى والفيديو من الجهاز، تنظيمهما محليًا، ثم التحكم بهما عبر مشغلات مخصصة وإعدادات قراءة وواجهة محفوظة؛ مع تصدير اختياري للسجل ومشاركة بطاقات مفضلة لا تكشف ملفات المستخدم أو مساراتها.

## البدء السريع

| المهمة | الأمر |
|---|---|
| تثبيت الحزم | `pnpm install` |
| تشغيل بيئة التطوير | `pnpm dev` |
| فحص TypeScript | `pnpm check` |
| فحص التنسيق والقواعد | `pnpm lint` |
| تشغيل الاختبارات | `pnpm test` |
| تشغيل Android أو iOS | `pnpm android` أو `pnpm ios` |
