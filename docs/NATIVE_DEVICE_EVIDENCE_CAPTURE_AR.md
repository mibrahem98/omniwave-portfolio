# بروتوكول جمع أدلة الاختبار الأصلي — OmniWave

**الحالة:** جاهز للتنفيذ؛ لا توجد نتائج أجهزة فعلية مرفقة حتى الآن.
**الغرض:** ملء `NATIVE_TEST_MATRIX_IOS_ANDROID.md` بأدلة قابلة للمراجعة من جهاز iOS وجهاز Android، من دون استخدام معاينة الويب بديلًا عن الاختبار الأصلي.

## قبل البدء

| عنصر | المطلوب |
| --- | --- |
| البناء | نسخة Expo Go أو development build موثقة برقم الإصدار والالتزام البرمجي. |
| الأجهزة | جهاز iOS وجهاز Android، مع الطراز وإصدار النظام. |
| الوسائط | ملف صوت وملف فيديو وVTT مرخصة، ولا يذكر اسمها أو مسارها في التقرير العام. |
| الخصوصية | عدم تصوير حسابات أو معرفات أو مسارات ملفات أو رموز. |
| التوثيق | تسجيل المعرّف والنتيجة ولقطة منقحة أو فيديو قصير لكل سيناريو. |

## ترتيب التنفيذ

نفذ كل صف في المصفوفة كما هو، وسجل `PASS` أو `FAIL` أو `NOT-VERIFIABLE` فقط. لا تحول عدم توفر ميزة جهاز إلى نجاح. ابدأ بـI-01 حتى I-05 وA-01 حتى A-04، ثم التشغيل والخلفية ومخرج الصوت، ثم الفيديو، ثم الإتاحة والتصدير.

| حزمة السيناريو | معرّفات المصفوفة | دليل القبول المختصر |
| --- | --- | --- |
| تثبيت وأذونات واستيراد | I-01..I-05, A-01..A-04 | لا تعطل، أقل إذن، ولا URI ظاهر. |
| صوت وخلفية ومخرج | I-06..I-08, A-05..A-07 | حالة واجهة متزامنة، وسلوك واضح عند القفل أو تبديل المخرج. |
| فيديو وتحكم | I-09..I-12, A-08..A-11 | عودة اتجاه آمنة، ترجمة مفهومة، وبدائل تحكم مرئية. |
| RTL وإتاحة وتصدير | B-02..B-05 | نص غير مقطوع، تحكم بلا لون وحده، ومخرجات منقحة. |

## قالب سجل النتيجة

انسخ هذا الصف لكل سيناريو منفذ داخل المصفوفة:

| الحقل | القيمة المطلوبة |
| --- | --- |
| المعرّف | مثال: `I-07` |
| التاريخ والمنفذ | التاريخ والمنفذ من دون معلومات شخصية زائدة |
| الجهاز والنظام | مثال: iPhone 15، iOS 18.x |
| البناء | رقم نسخة أو commit مختصر |
| النتيجة | `PASS` أو `FAIL` أو `NOT-VERIFIABLE` |
| الملاحظة | وصف سلوكي قصير؛ لا مسارات أو أسماء ملفات |
| الدليل | رابط أو اسم لقطة منقحة داخل مساحة العمل |
| عيب مرتبط | `DEF-xxx` أو «لا يوجد» |

## ما يرسل إلى الفريق

بعد التنفيذ، أرسل جدول النتائج ولقطات منقحة أو فيديوهات قصيرة لكل حالة فشل، مع طراز الجهاز وإصدار النظام فقط. عند استلامها، حدّث المصفوفة ولا تعدّل الصفوف غير المنفذة إلى PASS.

## حدود هذه البيئة

لا يمكن لهذا المسار تشغيل صوت فعلي أو تغيير مخرج Bluetooth أو قفل شاشة هاتف أو طلب أذونات نظام بالنيابة عنك. لذلك تظل هذه السيناريوهات غير قابلة للتحقق هنا حتى توفر الأدلة السابقة.
