# اللغات والتقنيات

## اللغات والملفات

| اللغة أو الصيغة | الاستخدام في المشروع |
|---|---|
| TypeScript (`.ts`, `.tsx`) | الشاشات، مكونات React Native، الحالة، الخادم، الاختبارات، والأنواع. |
| JavaScript (`.js`, `.mjs`) | إعدادات Metro وBabel وTailwind وسكربتات مساعدة. |
| JSON | الحزم، الإعدادات، وأقفال التبعيات. |
| CSS | `global.css` ومتغيرات NativeWind. |
| Markdown | متطلبات المنتج، التوثيق، خارطة الطريق، وسجل التحديثات. |

## طبقة الخادم والبنية الموروثة

يشمل القالب Express وtRPC وTanStack Query وDrizzle ORM وMySQL وطبقات OAuth والتخزين. هذه الإمكانات متاحة للبنية العامة، لكن مشغل الموسيقى المحلي لا يعتمد عليها لتخزين مكتبة المستخدم أو تفضيلاته في التدفق الأساسي.

## الجودة والأدوات

| الأداة | الأمر | النتيجة |
|---|---|---|
| TypeScript | `pnpm check` | كشف أخطاء الأنواع دون توليد ملفات. |
| ESLint | `pnpm lint` | مراجعة جودة الشفرة وقواعد Expo. |
| Vitest | `pnpm test` | اختبارات البيانات والترجمة والعقود المرئية والوظيفية. |

| Expo Config | `pnpm exec expo config --type public` | مراجعة إعدادات البناء الناتجة. |

## إعدادات البناء البارزة

* اتجاه التطبيق عمودي (`portrait`) مع هوية OmniWave وأيقونات iOS/Android/ويب.
* إضافة `expo-audio` مفعلة مع `enableBackgroundPlayback`، وتدعم البنية `expo-video` للفيديو المحلي.
* يحمل iOS وضع الخلفية `audio`، بينما يضبط Android أيقونة تكيفية و`POST_NOTIFICATIONS`.
* تُفعل مسارات Expo Router المكتوبة وReact Compiler في الإعدادات التجريبية.
