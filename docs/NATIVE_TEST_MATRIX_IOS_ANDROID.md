# OmniWave — مصفوفة الاختبار الأصلية لـ iOS وAndroid

> **حالة التنفيذ الحالية:** جاهزة للتنفيذ على أجهزة فعلية، لكن لا توجد حتى الآن نتائج هاتف موثقة في هذه البيئة. لذلك تظل جميع السيناريوهات المعلّمة **لم يُنفذ** ولا تمثل ادعاءً عن سلوك APK أو iOS الفعلي.

## بروتوكول التنفيذ

ينفذ المختبر كل صف على بناء محدد، باستخدام ملفات صوت وفيديو يملك حق استخدامها أو ملفات اختبار مفتوحة الترخيص. لا تحفظ في هذا الملف أسماء ملفات شخصية أو URIs أو لقطات تتضمن إشعارات أو حسابات أو بيانات خاصة. تسجل النتيجة كما ظهرت للمستخدم، ثم تربط دليلاً منقحاً عند الحاجة.

| الحالة | المعنى |
| --- | --- |
| **لم يُنفذ** | لا توجد نتيجة من جهاز فعلي بعد. |
| **ناجح** | تحققت النتيجة المتوقعة مع دليل منقح. |
| **فشل** | ظهرت مشكلة قابلة للتكرار وتحتاج معالجة. |
| **محجوب** | حال الإذن أو دعم الجهاز أو بيئة الاختبار دون التنفيذ. |

يستخدم منفذ الاختبار الملف [`NATIVE_DEVICE_EVIDENCE_CAPTURE_AR.md`](NATIVE_DEVICE_EVIDENCE_CAPTURE_AR.md) لتسجيل الطراز وإصدار النظام والبناء والدليل المنقح قبل تحديث أي صف في هذه المصفوفة.
