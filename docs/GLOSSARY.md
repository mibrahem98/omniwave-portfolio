# معجم OmniWave

| المصطلح | المعنى في المشروع |
|---|---|
| المسار (`Track`) | ملف صوتي صالح للتشغيل مع عنوان وفنان وألبوم وURI وحالة مفضلة. |
| URI صوتي | عنوان محلي أو عنوان يدعمه المشغل. يُتحقق منه قبل التخزين أو التشغيل. |
| المكتبة | المجموعة المحلية من المسارات المتاحة للبحث أو التشغيل أو التنظيم. |
| قائمة التشغيل (`Playlist`) | اسم ومصفوفة معرفات مسارات محفوظة محليًا. |
| قائمة الانتظار | مسارات لاحقة للتشغيل؛ تختلف عن قائمة التشغيل ولا تحفظ ترتيبًا دائمًا للمكتبة. |
| سجل التشغيل | معرفات أحدث المسارات المشغلة؛ يُستخدم للوصول السريع عند غياب المفضلة. |
| اللقطة (`PlayerSnapshot`) | حالة عرض مشتقة للمشغل تتضمن الوقت والتشغيل والتكرار والخلط والطابور. |
| Session Audio | إعداد نظام التشغيل الذي يحدد السلوك الصامت والخلفي والتداخلات. |
| Skeleton Loading | بنية مؤقتة غير تفاعلية تُعرض أثناء استعادة البيانات المحلية، لا أثناء الخطأ المستمر. |
| RTL | ترتيب واتجاه من اليمين إلى اليسار عند اختيار العربية. |

> استخدم الأسماء نفسها في أنواع TypeScript، مفاتيح الترجمة، الاختبارات، والوثائق لتفادي تضارب المفاهيم بين الواجهة وطبقة الحالة.
