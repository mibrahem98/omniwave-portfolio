# فهرس الملفات والمجلدات

لا يسرد هذا الملف `node_modules` أو مخرجات البناء، بل يصف الملفات التي تحتاج عادةً إلى قراءة أو تعديل عند تطوير OmniWave.

| المسار | المحتوى | متى يُعدّل؟ |
|---|---|---|
| `app/` | المسارات والشاشات | عند إضافة شاشة أو تعديل تدفق تنقل. |
| `app/(tabs)/_layout.tsx` | شريط التبويب و`PlayerProvider` وMini-player | عند تعديل التبويبات أو الكروم السفلي. |
| `app/(tabs)/index.tsx` | الرئيسية | عند تحسين جلسة الاستماع والوصول السريع. |
| `app/(tabs)/library.tsx` | المكتبة | عند تعديل الاستيراد أو البحث أو الفلاتر أو الوصول السريع. |
| `app/(tabs)/now-playing.tsx` | التشغيل الآن | عند تعديل التحكم المفصل أو حالات التشغيل. |
| `app/(tabs)/playlists.tsx` | نقطة دخول القوائم | تستدعي شاشة قوائم التشغيل. |
| `app/(tabs)/tools.tsx` | الأدوات | للطابور ومؤقت النوم. |
| `app/(tabs)/settings.tsx` | الإعدادات | للغة والثيم والمؤثرات والمعادل. |
| `app/(tabs)/videos.tsx` و`video-player.tsx` | الفيديو المحلي | للمكتبة والمشغل والترجمة والتقدم. |
| `app/(tabs)/export-history.tsx` | تصدير السجل | لاختيار البيانات والمعاينة وTXT/CSV والمشاركة. |
| `app/(tabs)/metadata-review.tsx` | مراجعة التصنيف | لتأكيد أو تعديل اقتراحات بيانات المسارات. |
| `components/omniwave/` | المكونات الخاصة بالموسيقى | للأغلفة، الصفوف، الموجة، Skeleton، والمشغل المصغر. |
| `components/screen-container.tsx` | حاوية المساحات الآمنة | لكل شاشة جديدة. |
| `lib/omniwave/player-store.tsx` | الحالة والمنطق المحلي | عند إضافة سلوك تشغيل أو مكتبة أو طابور. |
| `lib/omniwave/video-store.tsx` | حالة الفيديو المحلية | عند تغيير مكتبة الفيديو والترجمة والتقدم والقوائم. |
| `lib/omniwave/sharing.ts` | مشاركة وتصدير آمنان | عند تغيير مخطط السجل أو بطاقة المفضلة. |
| `lib/omniwave/vtt.ts` | WebVTT محلي | عند تغيير الترجمة أو البحث داخل الإشارات. |
| `lib/omniwave/types.ts` | العقود الأساسية | قبل تعديل شكل البيانات. |
| `lib/omniwave/data.ts` | بيانات أولية وثوابت | عند تعديل المسارات التجريبية أو تفضيلات افتراضية. |
| `lib/omniwave/validation.ts` | تحقق من URI | عند تغيير قواعد الاستيراد أو التشغيل. |
| `lib/localization.ts` | القواميس الأربعة | قبل إضافة أي نص واجهة جديد. |
| `lib/theme-provider.tsx` | الثيم وRTL والحفظ | عند إضافة ثيم أو تغيير سلوك اللغة. |
| `app.config.ts` | إعداد Expo والهوية الأصلية | عند تغيير اسم التطبيق أو الأيقونة أو الأذونات أو الصوت. |
| `assets/images/` | الأيقونات وصورة البداية | عند تحديث العلامة البصرية. |
| `tests/` | اختبارات Vitest | مع كل تغيير في البيانات أو الواجهة أو العقود. |
| `scripts/` | أدوات مساعدة | لتوليد QR أو أصول العلامة. |
| `server/` و`shared/` | بنية خادم وقواعد مشتركة | فقط عند إضافة احتياج خادمي صريح. |
